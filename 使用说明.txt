Galgame 解包工具 使用说明
================================

【目前支持范围】
  1. Unity 引擎（Naninovel 资源结构）
  2. KiriKiri 引擎（.xp3 资源包）

  注意：KiriKiri 部分使用统一提取逻辑，自动识别资源包并分类：
  - bgm.xp3 / data.xp3 中 bgm 开头的音频 -> BGM
  - bgimage.xp3 的图片 -> 背景
  - evimage.xp3 的 png/pimg、vol*.xp3 的 ev*.png -> CG
  - fgimage.xp3 的 tlg/webp -> 立绘
  已实测《魔女的夜宴》《ATRI》《千恋万花》均可正常提取。

这是什么？
-----------
一个整合版解包工具，双击启动后选择游戏目录和输出目录，自动识别并解包。
解包过程中会实时显示（已完成/总数）进度。

怎么使用
---------
1. 双击“release\Galgame解包工具.exe”（release 目录是完整可运行版）。
2. 点击【选择目录】选择已解压的游戏根目录：
   - Unity：选择包含 manosaba_Data 和 manosaba.exe 的文件夹
   - KiriKiri：选择包含 evimage.xp3、fgimage.xp3 等文件的文件夹
   （如果拿到的是压缩包，请先用 7-Zip / WinRAR / Bandizip 等工具自行解压）
3. 点击【选择输出】，选择输出位置（建议选一个空文件夹或专门放提取结果的目录）。
4. 在【文件夹名】输入框里自定义输出文件夹名（默认“提取资源”）。
5. 点击【开始解包】。
6. 等日志显示【全部完成】即可。

输出位置
---------
在你选择的输出目录下自动生成你填写的文件夹（默认叫“提取资源”）：

    提取资源（可自定义名字）

里面固定包含四个文件夹：
  - BGM
  - CG
  - 背景
  - 立绘

所有解包出来的文件都会按类型放进这四个文件夹里。
Unity 引擎：stills 静态图放 CG，mainbackground / tricks 放背景；
KiriKiri 引擎：背景直接放在“背景”里。

提速说明
---------
- 解包过程会自动使用多线程并行转换图片，比旧版更快。
- 不再在输出目录里留下 _pimg_raw / _tlg_raw 等中间文件夹，
  临时文件使用系统临时目录，完成后自动清理。

断点续跑
---------
如果中途关闭，重新打开工具，再次选择同一个目录开始即可。
已经成功提取的文件会自动跳过。

日志
-----
release 目录下的“解包日志.txt”会记录完整过程。

命令行模式（可选）
-------------------
不想用图形界面时，也可以在 cmd / PowerShell 里运行：

    release\Galgame解包工具.exe --cli <游戏目录> <输出目录> [输出文件夹名]

例如：

    release\Galgame解包工具.exe --cli "游戏目录" "输出目录" 我的资源

依赖
-----
release 版本不需要安装 Python，整个 release 文件夹一起使用即可。
从源码运行请先安装 requirements.txt 中的依赖。

注意
-----
- 本工具只做资源解包，不修改游戏原始文件。
- 解包结果仅供个人学习、备份使用，请遵守当地法律和游戏用户协议。
